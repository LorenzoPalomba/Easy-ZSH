# Easy-ZSH
A projet for people that want to learn zsh in a simple metod zsh

1. Download the Download the most recent relase and open the file for you operating sistem (linux with zsh or macOS)
2. Move the folder of your operating system in the documents folder
3. Start the file Easy-ZSH
4. Login with sudo
5. Select a passcode for open the file
6. Enjoy the learning!
