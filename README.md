# Easy-ZSH
A project for people that want to learn zsh in a simple method zsh

1. Download the most recent release and open the file for your operating system (linux with zsh or macOS)
2. Move the folder specific to your operating system in the documents folder (Optional)
3. Execute chmod a+x [Path of Easy-ZSH]
5. Start the file Easy-ZSH
6. Enjoy learning!
